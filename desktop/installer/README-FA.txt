MIKA AI VPN برای Windows 10/11 x64

روش اجرا:
1) کل فایل ZIP را در یک پوشه استخراج کنید.
2) روی INSTALL.ps1 راست‌کلیک کنید و Run with PowerShell را انتخاب کنید.
3) اگر Windows برای نصب پیش‌نیاز Microsoft درخواست دسترسی مدیر کرد، فقط در صورت نمایش امضای معتبر Microsoft آن را تأیید کنید.
4) پس از بررسی پیش‌نیاز، برنامه MIKA-AI-VPN.exe اجرا می‌شود.

نکات:
- نسخهٔ این بسته .NET 8 و Windows Desktop Runtime را همراه خود دارد؛ نصب جداگانهٔ .NET 8 لازم نیست.
- اگر Visual C++ Runtime x64 موجود نباشد، اسکریپت نسخهٔ رسمی را مستقیماً از دامنهٔ Microsoft دریافت و امضای دیجیتال آن را بررسی می‌کند.
- برای اجرای مستقیم EXE، پیش‌نیازهای Microsoft Visual C++ x64 باید از قبل نصب باشند.
- ابزار Diagnostics فقط بارگذاری و بررسی اولیهٔ کتابخانه‌های Native را انجام می‌دهد؛ به‌تنهایی اتصال VPN یا عبور واقعی ترافیک را تأیید نمی‌کند.
- تا زمان تکمیل تست واقعی تونل، دکمهٔ اتصال VPN در برنامه غیرفعال باقی می‌ماند.

این بسته آزمایشی است و هنوز امضای Authenticode اختصاصی MIKA AI ندارد.
